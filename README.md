# 🌸 Felicity (Фелисити) — Autonomous Humanized Telegram AI Userbot

Фелисити — это полностью автономный Telegram-юзербот с человеческим поведением, широким кругозором, голосовым интеллектом, зрением картинками (GPT-4o Vision), глобальным поиском групп в Telegram и спонтанным проактивным мышлением.

## ✨ Возможности
- 🧠 **Флагманское ядро GPT-4o**: Высокий интеллект, глубокий эрудированный контекст, отсутствие корпоративной цензуры.
- 🌐 **100% Глобальный Поиск Telegram**: Фелисити сама ищет новые публичные группы и чаты в Telegram по случайным поисковым запросам и вступает в них.
- 💬 **Самообучение и Комментирование**: Читает посты в группах, сохраняет мысли в свою базу знаний и обсуждает посты в тредах.
- 💖 **Спонтанные сообщения 100% Zero-Touch**: Сама пишет первыми нежные, непредсказуемые и интересные личные сообщения каждые 15–30 минут на указанный аккаунт.
- 📸 **Зрение ПК и Фото (GPT-4o Vision)**: Распознавание отправленных фотографий и скриншотов.

## 🚀 Быстрый запуск на VPS (Ubuntu 22.04 / 24.04)

```bash
# 1. Клонируем репозиторий
git clone https://github.com/ВАШ_НИК/felicity.git
cd felicity

# 2. Создаем окружение и устанавливаем библиотеки
python3 -m venv venv
source venv/bin/activate
pip install telethon requests pillow opencv-python-headless py-cpuinfo psutil tomly

# 3. Настраиваем конфигурацию
cp config.example.toml config.toml
nano config.toml # Вкажите ваш API ключ и Telegram API данные
```

Запуск юзербота:
```bash
python3 felicity_userbot.py
```
